# Integrated Business Planning

نرم‌افزار **برنامه‌ریزی یکپارچه کسب‌وکار (IBP)** برای **هلدینگ صنایع غذایی** — فارسی، راست‌چین، با تقویم شمسی و قمری و دوره‌های ماهانه.

هلدینگ از چند شرکت تولیدی تشکیل شده و **هر شرکت IBP و منطق خودش را دارد**. در ورود، شرکت (کد شرکت = کد پلنت) انتخاب می‌شود و کاربر وارد فضای کاری همان شرکت می‌شود. داده‌های هر شرکت در پایگاه داده جداگانه نگه‌داری می‌شود.

## اجرا

### برنامه (بدون نیاز به نصب یا اینترنت)

1. پوشه `app` را باز کنید.
2. روی `index.html` دوبار کلیک کنید (Chrome یا Edge).

در اولین اجرا، هلدینگ نمونه «هلدینگ صنایع غذایی آوا» با پنج شرکت ساخته می‌شود:

| کد | شرکت | محصولات | ویژگی برنامه‌ریزی |
|---|---|---|---|
| PAS | ماکارون آوا | ماکارونی، اسپاگتی، رشته | اثر محرم (نذری) و رمضان (آش رشته) |
| FLR | آرد آوا | آرد نانوایی، آرد خانگی، سمولینا | تأمین‌کننده درون‌گروهی ماکارون و بیسکویت |
| BIS | بیسکویت و شیرینی آوا | بیسکویت، کیک، زولبیا و بامیه، گز و سوهان | جهش شدید زولبیا در رمضان، اوج نوروزی گز |
| DAI | لبنیات آوا | شیر، ماست، پنیر، دوغ | ماندگاری کوتاه، اوج تابستانی دوغ |
| OIL | روغن آوا | روغن مایع، جامد، روغن صنعتی | تأمین‌کننده شورتنینگ برای بیسکویت |

از صفحه ورود می‌توانید شرکت جدید (خالی یا با داده نمونه یکی از الگوها) اضافه، ویرایش یا حذف کنید.

### موتور تحلیل پایتون (اختیاری، برای تحلیل پیشرفته)

برنامه بدون موتور کامل کار می‌کند. با اجرای موتور، مدل‌های آماری پیشرفته‌تر و خروجی Excel همراه با نمودار فعال می‌شود.

- **ویندوز:** پایتون ۳٫۱۰ یا جدیدتر را نصب کنید و `engine/start_engine.bat` را اجرا کنید.
- **لینوکس/مک:** `engine/start_engine.sh`

موتور روی `http://127.0.0.1:8765` اجرا می‌شود و برنامه خودکار متصل می‌شود.

## امکانات

| بخش | توضیح |
|---|---|
| ورود هلدینگ | انتخاب شرکت، نمای تلفیقی هلدینگ (فروش بیرون از گروه، تناژ، دقت پیش‌بینی، استثناها)، افزودن/ویرایش/حذف شرکت |
| برنامه‌ریزی تقاضا | **برنامه اجماعی**: جدول ماهانه شرکت ← خانواده ← محصول، ویرایش در هر سطح با تفکیک متناسب، واحد مقدار/تن/مبلغ، افق منجمد، دلیل و سوابق تغییر، بازگشت، تغییر درصدی، ورود و خروج Excel |
| | **پیش‌بینی آماری**: انتخاب خودکار بهترین روش هر محصول با اعتبارسنجی چرخشی (هولت-وینترز، روند میرا، رگرسیون فصل و مناسبت، کراستون/TSB، ترکیب مدل‌ها) و بازه اطمینان ۸۰٪ |
| | **دقت و ارزش افزوده (FVA)**: مقایسه پیش‌بینی ساده، آماری و اجماعی؛ سوگیری و سیگنال ردیابی |
| | **مناسبت‌ها**: محاسبه خودکار رمضان و دهه محرم از تقویم قمری برای هر ماه شمسی، اثر هر مناسبت بر هر خانواده، برآورد آماری اثر از داده تاریخی با بازه اطمینان |
| | **تقاضای درون‌گروهی**: محاسبه نیاز شرکت‌های خریدار از برنامه آن‌ها و فهرست مواد و به‌روزرسانی برنامه شرکت تأمین‌کننده |
| | **بازنگری تقاضا**: شکاف با بودجه و سال قبل (تن و ریال)، ریسک‌های خارج از بازه آماری، بسته Excel جلسه |
| مرکز داده | الگوهای آماده شرکت‌های غذایی، الگوی Excel با راهنما و فهرست کشویی، اعتبارسنجی پیش از اعمال، امتیاز کیفیت داده |
| داشبورد و پورتفوی | شاخص‌های کلیدی، روندها، ظرفیت، هشدارها، ماتریس ABC-XYZ، پارتو، نقشه رشد و سودآوری، بخش‌بندی هوشمند |
| خروجی Excel | در همه بخش‌ها؛ راست‌به‌چپ و قالب‌بندی‌شده؛ با موتور پایتون همراه نمودارهای بومی Excel |

## ساختار پروژه

```
app/                         برنامه (HTML/CSS/JavaScript، بدون وابستگی اینترنتی)
  js/core/holding.js         فهرست شرکت‌ها و فضای کاری (پایگاه داده) هر شرکت
  js/core/events.js          تقویم مناسبت‌ها (رمضان و محرم از تقویم قمری ام‌القری)
  js/core/forecast.js        پیش‌بینی آماری داخلی و برآورد اثر مناسبت‌ها
  js/modules/gate.js         صفحه ورود هلدینگ
  js/modules/demand.js       برنامه‌ریزی تقاضا
  js/data/templates.js       الگوهای شرکت‌های غذایی
  vendor/exceljs/            کتابخانه ExcelJS (MIT)
engine/                      موتور تحلیل پایتون (FastAPI)
  ibp_engine/demand.py       پیش‌بینی آماری و برآورد اثر مناسبت‌ها
  ibp_engine/portfolio.py    تحلیل پورتفوی
  ibp_engine/reports.py      گزارش Excel با نمودار
  tests/                     آزمون‌های خودکار (pytest)
```

## نکات روش‌شناختی

- مناسبت‌های قمری هر سال حدود ۱۱ روز جابه‌جا می‌شوند؛ ضریب فصلی ماه شمسی آن‌ها را نمی‌گیرد. شدت مناسبت در هر ماه (سهم روزهای ماه) محاسبه و در مدل‌ها لحاظ می‌شود. نوروز، بازگشایی مدارس و تابستان در فصلی‌بودن مدل‌ها دیده می‌شوند.
- برای شناسایی اثر مناسبت‌ها حداقل سه سال سابقه لازم است؛ داده نمونه ۳۶ ماه سابقه دارد.
- مقایسه با بودجه فقط در ماه‌هایی انجام می‌شود که بودجه ثبت شده است.

## آزمون موتور

```
cd engine
python -m pip install -r requirements.txt pytest httpx
python -m pytest
```
