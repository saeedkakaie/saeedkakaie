# Integrated Business Planning

نرم‌افزار جامع **برنامه‌ریزی یکپارچه کسب‌وکار (IBP)** برای شرکت‌های تولیدی — فارسی، راست‌چین، با تقویم شمسی و دوره‌های ماهانه.

## اجرا

### برنامه (بدون نیاز به نصب یا اینترنت)

1. پوشه `app` را باز کنید.
2. روی `index.html` دوبار کلیک کنید (Chrome یا Edge).

در اولین اجرا، داده تستی یک شرکت «صنایع غذایی» ساخته می‌شود. از **مرکز داده** می‌توانید الگوی صنعت دیگر (لوازم خانگی، دارویی، قطعات خودرو) یا فایل Excel داده‌های خودتان را بارگذاری کنید. داده‌ها در پایگاه داده محلی (IndexedDB) ذخیره می‌شوند.

### موتور تحلیل پایتون (اختیاری، برای تحلیل پیشرفته)

برنامه بدون موتور کامل کار می‌کند. با اجرای موتور، تحلیل‌های آماری پیشرفته و خروجی Excel همراه با نمودار فعال می‌شود.

- **ویندوز:** پایتون ۳٫۱۰ یا جدیدتر را نصب کنید و فایل `engine/start_engine.bat` را اجرا کنید.
- **لینوکس/مک:** `engine/start_engine.sh`

بار اول کتابخانه‌ها در `engine/.venv` نصب می‌شوند. موتور روی `http://127.0.0.1:8765` اجرا می‌شود و برنامه خودکار متصل می‌شود (وضعیت در پایین منوی کناری نمایش داده می‌شود).

| خروجی Excel | در همه بخش‌ها: داشبورد کامل یا هر کارت، پورتفوی، داده‌های پایه، چرخه IBP، کیفیت داده؛ راست‌به‌چپ، قالب عددی، فیلتر و رنگ‌بندی وضعیت؛ با موتور پایتون همراه نمودارهای بومی Excel |
| چرخه ماهانه IBP | شش مرحله استاندارد با مسئول، سررسید و وضعیت |
| داده‌های پایه | ۱۸ بخش داده با افزودن، ویرایش، حذف (با کنترل وابستگی)، جستجو، فیلتر، ورود و خروج Excel |

## ساختار پروژه

```
app/                         برنامه (HTML/CSS/JavaScript، بدون وابستگی اینترنتی)
  index.html
  assets/                    استایل، فونت وزیرمتن (OFL)
  vendor/exceljs/            کتابخانه ExcelJS (MIT) برای ساخت و خواندن فایل xlsx
  js/core/                   تقویم، قالب‌بندی، تعریف موجودیت‌ها، لایه داده، تحلیل‌ها، Excel، موتور پایتون
  js/components/             نمودار، فرم، جدول، جستجوی فرمان
  js/data/                   الگوهای صنعت و مولد داده تستی
  js/modules/                صفحه‌ها
  tools/                     ابزارهای توسعه
engine/                      موتور تحلیل پایتون (FastAPI)
  ibp_engine/                تحلیل پورتفوی و ساخت گزارش Excel با نمودار
  tests/                     آزمون‌های خودکار (pytest)
```

## معماری

- **تعریف موجودیت‌ها (`schema.js`):** فرم‌ها، جدول‌ها، الگوی Excel، اعتبارسنجی ورود داده و کنترل وابستگی‌ها همه از همین تعریف ساخته می‌شوند. برای افزودن فیلد یا بخش جدید کافی است همین فایل تغییر کند.
- **لایه داده (`store.js`):** آداپتور فعلی IndexedDB است؛ در فاز سرور، آداپتور API با همان رابط جایگزین می‌شود.
- **موتور تحلیل:** محاسبات تعاملی در خود برنامه انجام می‌شود؛ محاسبات آماری سنگین و گزارش‌های نموداردار در موتور پایتون. اگر موتور در دسترس نباشد، برنامه با محاسبات پایه ادامه می‌دهد.
- **دستیار هوشمند (فاز ۷):** از همین موتور پایتون برای پرس‌وجو، تحلیل و ساخت نمودار و فایل استفاده خواهد کرد.
