# بسته پیاده‌سازی IBP در Power BI

این پوشه همه چیزهایی است که برنامه‌نویس Power BI برای ساختن همان فرایند IBP برنامه (پورتفوی، پیش‌بینی، اجماع، برنامه تولید و ظرفیت، موجودی و مواد، مالی و سناریو، جلسه مدیریت) لازم دارد. همه فرمول‌ها از کد برنامه گرفته شده‌اند و محاسبات پایتون با خروجی خود برنامه آزموده شده‌اند (بیشترین اختلاف نسبی ۶٫۷×۱۰⁻¹⁵).

**از سند شروع کنید:** `docs/IBP-PowerBI-Spec.html` (فارسی، قابل چاپ). منطق هر مرحله، مدل داده، صفحات گزارش و اعداد مرجع آزمون در آن آمده است.

| مسیر | محتوا |
|---|---|
| `docs/IBP-PowerBI-Spec.html` | سند مشخصات (ساخته‌شده از `docs/spec.src.html` با `tools/build_spec.py`) |
| `powerquery/queries.pq` | کوئری‌های Power Query (M) |
| `dax/measures.dax` | اندازه‌ها و ستون‌های محاسباتی DAX |
| `python/ibp_pbi.py` | پیش‌بینی آماری، برنامه تولید (MPS)، MRP، بهای تمام‌شده، سود و زیان، سناریو و مونت‌کارلو |
| `data/calendar_lunar.csv` | تقویم ماهانه شمسی ۱۳۹۸ تا ۱۴۲۰ با روزهای رمضان و دهه محرم |
| `tools/export_data.py` | خروجی CSV ورودی‌ها از سرور مرکزی (`--db`) یا پشتیبان کامل هلدینگ (`--backup`) |
| `tools/validate.py` | مقایسه محاسبات پایتون با نتایج مرجع برنامه |
| `tools/export_sample.js` | ساخت داده نمونه و نتایج مرجع از خود برنامه (Playwright) |
| `tools/schema_columns.json` | ستون‌های هر جدول از تعریف جدول‌های برنامه |

## اجرا (از داخل همین پوشه)

```
pip install -r python/requirements.txt

# داده واقعی از سرور مرکزی (پوشه داده سرور، جایی که ibp.db است)
python tools/export_data.py --db "D:\IBP-Server\data" "C:\IBP\data"

# محاسبات برای Power BI
python python/ibp_pbi.py "C:\IBP\data" "C:\IBP\out" --forecast --scenarios --mc 5000
```

`ibp_pbi.py` موتور برنامه را از کنار خودش (`python/ibp_engine` در بسته) یا از مخزن (`engine/ibp_engine`) پیدا می‌کند.

## آزمون

```
node tools/export_sample.js <پوشه نمونه>      # داده نمونه + نتایج مرجع از برنامه
python tools/validate.py <پوشه نمونه>          # باید WORST < 1e-6 باشد
python tools/build_spec.py <پوشه نمونه>        # بازسازی سند با اعداد مرجع تازه
```

فایل‌های DAX و M با منطق برنامه نوشته و با معادل پایتون آزموده شده‌اند اما در Power BI Desktop اجرا نشده‌اند؛ معیار پذیرش، برابری اعداد گزارش با جدول اعداد مرجع سند است.

## مدل اکسل فرمول‌نویسی‌شده (برای نمایش در Power BI)

`excel/build_excel_model.py` یک فایل اکسل برای هر شرکت می‌سازد که همه مراحل IBP را با فرمول اکسل حساب می‌کند: شیت‌های «ورودی_…» (زرد) داده را می‌گیرند، شیت‌های «م۱» تا «م۱۰» مرحله به مرحله محاسبه می‌کنند و شیت‌های «خروجی_…» جدول تخت آماده Power BI هستند. شیت «راهنما» کار برنامه‌نویس را قدم به قدم توضیح می‌دهد.

```
python excel/build_excel_model.py <پوشه داده CSV> <کد شرکت> IBP-Model.xlsx
```
